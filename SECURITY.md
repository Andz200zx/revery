# security

revery holds an immich api key and provides access to its owner's photographs.
use a dedicated key, a strong app password and trusted https. keep it on a
private network or tailnet. it has not had an independent security audit.

please report security issues through the repository's **security → report a
vulnerability** page. include the affected version and a description of the
problem. use sample data; do not include api keys, passwords, session cookies,
private photographs or location metadata.

only the latest version on `main` is maintained. normal bugs and feature
requests can go in public issues. remove private addresses, filenames and
metadata from screenshots and logs before posting them.
